# Вишлист на день рождения

Гости открывают ссылку и выбирают подарок. Подарок можно забронировать, можно скинуться на него вместе с другими, а можно отметить, что даришь что-то своё. Именинник добавляет подарки с фото в панели `#admin`.

Сайт лежит на GitHub Pages, а брони хранятся в бесплатной базе Firebase, потому что GitHub Pages умеет только показывать файлы.

Пока Firebase не подключён, сайт работает в демо-режиме: данные сохраняются только в твоём браузере и гости их не увидят.

## Как запустить для всех

### 1. Создать проект Firebase

1. Открой [console.firebase.google.com](https://console.firebase.google.com) и войди через Google.
2. Нажми **Create a project**, назови, например, `wishlist`. Google Analytics можно выключить.
3. Тарифа Spark, он бесплатный, хватит с запасом. Привязывать карту не нужно.

### 2. Включить базу и вход

1. **Build → Firestore Database → Create database**. Выбери регион `eur3` и **production mode**.
2. На вкладке **Rules** вставь содержимое файла `firestore.rules`, замени `ЗАМЕНИ_НА_СВОЮ_ПОЧТУ` на свою почту маленькими буквами и нажми **Publish**.
3. **Build → Authentication → Get started**. На вкладке **Sign-in method** включи **Email/Password** и **Anonymous**. Анонимный вход нужен, чтобы гость мог снять свою бронь, а чужую не мог.
4. На вкладке **Users** нажми **Add user**: укажи ту же почту и придумай пароль. С ними ты будешь входить в панель.

### 3. Вписать настройки в сайт

1. Нажми на шестерёнку → **Project settings** → внизу значок **`</>`** (Web app) → **Register app**.
2. Скопируй объект `firebaseConfig` и вставь его в `js/config.js` вместо `null`.

Получится так:

```js
export const config = {
  firebase: {
    apiKey: '...',
    authDomain: '...',
    projectId: '...',
    storageBucket: '...',
    messagingSenderId: '...',
    appId: '...',
  },
  // defaults оставь как есть
};
```

Эти ключи можно спокойно хранить в открытом репозитории: они только указывают на проект, а защищают данные правила из `firestore.rules`.

### 4. Выложить на GitHub

1. Создай на [github.com/new](https://github.com/new) публичный репозиторий, например `wishlist`.
2. Выгрузи в него все файлы этой папки, кроме `firestore.rules`: в нём твоя почта, а сайту он не нужен.
3. В репозитории открой **Settings → Pages**, в **Branch** выбери `main` и `/ (root)`, нажми **Save**.
4. Через пару минут сайт откроется по адресу `https://ТВОЙ_ЛОГИН.github.io/wishlist/`. Эту ссылку и отправляй гостям.

### 5. Заполнить вишлист

Открой `https://ТВОЙ_ЛОГИН.github.io/wishlist/#admin` и войди. Там можно добавить подарки и фото, поменять порядок, указать заголовок и дату, а ещё убрать любую бронь.

## Как это устроено

- `index.html`, `css/style.css` — страница и дизайн.
- `js/app.js` — интерфейс и панель именинника.
- `js/store.js` — работа с данными: Firebase или демо-режим.
- `js/config.js` — настройки.
- `firestore.rules` — кто что может менять в базе.
- `vendor/firebase.js` — собранная библиотека Firebase 12.19 (только вход и Firestore).

Запустить у себя на компьютере:

```bash
python -m http.server 8774
```

## Что важно знать

- Имена гостей видны всем, в том числе имениннику. Сюрприз лучше не называть в комментарии.
- Снять свою бронь гость может только с того же телефона или компьютера, с которого бронировал. Если он сменил устройство, бронь снимает именинник в панели.
- Деньги сайт не собирает: сумма в складчине — это только отметка, сколько человек собирается скинуть.
